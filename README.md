# Happy English Kids 🌈
Vue 3 + Vite kid-friendly English learning site.
Features: A-Z, phonics, browser text-to-speech, English/Khmer vocabulary, categories, quiz, progress and responsive design.
Run: `npm install` then `npm run dev`.
Build: `npm run build`.
Next phase: connect Java Spring Boot + PostgreSQL for accounts, lessons, audio/images, quizzes, badges and progress reports.
